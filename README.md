# Ruska Trupa Chavka

Digital implementation of Ruska Trupa, also known as Chavka or Ruska Troyka.

The planned architecture is web-first and C#-centric:

- Blazor WebAssembly PWA for the primary app.
- Separate C# core rules engine.
- Separate C# AI engine for two simulated players.
- Optional later Windows shell through .NET MAUI Blazor Hybrid or WinUI.
